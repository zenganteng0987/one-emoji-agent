My AI agent in one emoji: 🧩

An agent takes a messy job, breaks it into pieces, and fits them together
into a finished answer. The puzzle piece says that in one glyph — no robot,
no smiley, no caption needed.

## How it works

`main.ts` writes a single emoji to `/output/entry.txt`:

```sh
node main.ts
```
